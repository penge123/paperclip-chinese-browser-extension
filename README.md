# paperclip汉化浏览器插件

这个插件只改变本机浏览器中 Paperclip 的固定界面文字，不修改官方 Paperclip 源码、API、数据库、智能体指令或你填写的内容。它使用随插件打包的人工审校词库，不调用在线翻译。`Agent` 一律译为“智能体”，不会译成“特工”或“代理”。

## 安装到 Microsoft Edge

1. 先在此目录运行 `npm ci`、`npm test`、`npm run build`，确认生成 `dist/content.js`。交付版本已附带构建文件，日常安装不需要运行这些命令。
2. 在 Edge 地址栏打开 `edge://extensions`。如未开启“开发人员模式”，由你自行开启。
3. 点击“加载解压缩的扩展”，选择**包含 `manifest.json` 的本仓库文件夹**。
4. 打开或刷新 `http://localhost:3100/`。如果官方服务使用其他端口，`http://localhost:<端口>/` 或 `http://127.0.0.1:<端口>/` 也在匹配范围内。
5. 修改词库后重新运行 `npm run build`，然后在 `edge://extensions` 中点击此插件的“重新加载”，再刷新 Paperclip 页面。

不想使用时，在 `edge://extensions` 中关闭或移除插件，再刷新页面即可恢复官方英文。插件仅申请上述两个本机网址的页面访问权限，不需要账户、API 密钥或网络翻译服务。它会进一步检查页面标记，只在识别到 Paperclip 时运行，不应影响其他本地网站。

## 汉化范围与术语

词库覆盖当前版本的导航、引导、仪表盘统计与图表、活动记录、搜索页及筛选菜单、新建任务弹窗及其状态/模式菜单、收件箱、任务、项目、例行任务、产出物、智能体详情与运行详情、技能库、连接器、费用、预算和设置中的固定界面文案。弹窗及其他动态载入的界面也会翻译。动态新增或尚未审校的英文仍保持原样；这比错误地翻译专业术语或用户内容更安全。插件不会翻译任务名称或描述、聊天/智能体输出、代码块、可编辑内容、CLI/终端日志，也不会翻译 Paperclip 服务端返回的自由文本。尤其在智能体运行详情和收件箱通知中，原始报错、运行摘要、转录、JSON、产品名、人员/智能体名称及事件代码会保留原文，方便核查。

| 英文 | 统一译法 |
| --- | --- |
| Agent | 智能体 |
| Model | 模型 |
| Tool | 工具 |
| Skill | 技能 |
| Prompt | 提示词 |
| Workflow | 工作流 |
| Heartbeat | 心跳 |

`Issue`、`Run` 等词会依据界面位置处理，不做全局替换。若官方更新改变了组件结构或文案，部分文字可能重新显示英文；更新 `src/phrases.js` 或 `src/dom.js` 并重新构建插件即可，不必修改官方 Paperclip 仓库。

## 更新与数据

汉化插件与 Paperclip 程序目录完全分离。官方 Git 仓库可以保持干净并使用 `git pull --ff-only` 更新；更新后需要按官方要求安装依赖/重启。你的实例数据不保存在插件中。**但官方新版启动可能迁移数据库，所以每次程序升级前仍需备份完整实例**；仅仅更新或关闭插件不会触发数据库迁移。

## 验证与已知限制

- `npm test` 测试页面识别、术语、动态更新、重复运行以及对用户内容的排除。
- `npm run build` 生成 Edge 可加载的 `dist/content.js`。
- 已在本机运行的官方 Paperclip 上检查上述主要页面和新建任务弹窗。当前词库针对已检查版本；官方以后新增文案或改变页面结构时，不保证自动保持 100% 汉化。
- 浏览器内的最终目视检查应包括：引导、仪表盘、导航、智能体、任务、项目、设置、弹窗、用户自行输入的内容及其他 localhost 网站。若某页仍有英文，可记录具体页面/原文继续补充词库。
